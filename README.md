# Gamini Sri Sanjeev — Upanayanam

A vector-illustrated invitation website for the Upanayanam (sacred thread / second birth) ceremony of **Gamini Sri Sanjeev**.

Built with React, Vite, Tailwind CSS, Framer Motion, and Radix-based UI primitives (shadcn-style).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Sections

- Hero with custom mandap vector art
- Ceremony meaning (sacred thread)
- Day timeline
- Venue details
- Blessings / RSVP form
